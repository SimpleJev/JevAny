# Agent-harness evaluation v1

This directory contains the portable, generated summaries used by the
agent-harness appendix:

- `formal-matrix.{md,json}`: 96 paired comparisons (192 agent episodes) across FrozenLake, Sokoban,
  WebShop, and the fixed six-task WebArena sample.
- `terminal-bench-sample-v3.{md,json}`: one exploratory D0/D3 pair for each of
  six predeclared Terminal-Bench 2 tasks.
- `terminal-bench-frontier-v4.{md,json}`: the exploratory SQLite/regex-log
  0%/50%/100% target-delegation sweep.

The JSON files retain relative local source paths and SHA-256 hashes for audit,
but raw `runs/` artifacts are intentionally excluded from the repository. They
contain development logs and environment-specific paths. The Markdown and JSON
summaries are generated by the corresponding `scripts/summarize_*` programs.

Only the repeated GPT-5.6-sol/FrozenLake cell is presented as a clear
multi-metric win. Terminal-Bench and single-task browser traces are exploratory;
frontier API cost excludes Jev serving cost.
