用统一 API 完成决策

发送当前状态和候选选项，JevAny 返回选择结果及其概率。应用可据此执行操作，或请求人工复核。

  1. 使用已发布模型

    加载模型权重，通过 Python 或 HTTP 调用 API。

  2. 用自己的数据训练

    使用带标注的决策数据适配模型。RLCR 后续训练仍处于实验阶段。

API 参考 →
分派客服工单Python
from jevany import Choice, JevClient

jev = JevClient("http://127.0.0.1:8008")
result = jev.system_one(
    state={"ticket": "I was charged twice."},
    questions={
        "department": Choice(
            instructions="Which team?",
            criteria={
                "billing": "Payment problems",
                "shipping": "Delivery problems",
            },
        ),
    },
)

快速开始

根据你的 CPU 或 GPU 选择模型，在本地加载后修改输入，查看它的决策结果。

本地运行指南 → 浏览已发布模型 ↑ 观看回放 →
1. 启动模型
git clone https://github.com/SimpleJev/JevAny.git
cd JevAny
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[train,serve]'
jevany data init --out data/starter
OMP_NUM_THREADS=4 jevany train --config recipes/sft.toml \
  --device cpu --dtype fp32 --weights-dtype fp32 \
  --out runs/cpu-jev
OMP_NUM_THREADS=4 jevany serve --checkpoint runs/cpu-jev \
  --device cpu --dtype fp32 --port 8008

CPU · 建议至少 16 GB 内存。下载 Qwen 0.8B 基础模型，用内置工单数据训练一个小型适配器，然后启动模型。

2. 在同一项目目录打开第二个终端
source .venv/bin/activate
jevany demo --base-url http://127.0.0.1:8008 --text-only

打开 localhost:8090，点击 Test and connect（测试并连接），然后修改 Try your own decision（尝试自定义决策） 中的输入，再点击 Ask the model（询问模型）.
